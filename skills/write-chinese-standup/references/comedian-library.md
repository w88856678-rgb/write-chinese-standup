# 中文脱口秀演员种子库

核查日期：2026-10-02。以下 12 位是不同学习入口，不是“2026 最火榜”。作品样本以 2021–2025 年可核查资料为主，并不覆盖 2026 年全部新作或在演专场。基本范围为大陆普通话单口喜剧；其他中文地区与语言需要补充当地样本。

本次核查读取了公开页面、目录和采访，**没有据此声称观看完整视频**。每卡的“观察任务／练习”为本技能原创设计，不是演员自述或对其全部作品的结论。只有官方目录的条目是探索候选；实际推荐为“相似演员”前，应按[匹配规则](comedian-matching.md)补足机制证据。

## 查找入口

| 要探索的问题 | 可先检索的演员 | 提醒 |
|---|---|---|
| 克制表达、内心活动如何变成内容 | 鸟鸟 | 内向不是充分匹配理由 |
| 小动作、具体人物怎样形成场景 | 周奇墨、刘旸 | 两人的表演方式不能仅凭题材认定相同 |
| 工作流程、制度与个人困境 | 呼兰 | 职场主题不等于已经有笑点 |
| 日常身份和别人眼光的反差 | 何广智、徐志胜 | 不把外貌、贫穷作为作者必须复刻的人设 |
| 亲密关系、社会期待与个人选择 | 小鹿、唐香玉 | 先比较作者位置，不能按性别分组推荐 |
| 想练身体参与和外放表达 | 付航、刘旸 | 没有视听证据时，能量与节奏仍待观察 |
| 个人观念、较真与反常推演 | 于祥宇 | 官方标题只支持题材定位 |
| 自我评价、消费与日常社交 | 漆漆 | 先研究具体作品，不套“自信型”标签 |
| 人生转变、代际与职业新体验 | 房主任 | 不借别人的经历给作者制造创伤或逆袭 |

## 有访谈依据的学习入口

### 鸟鸟

- **依据**：2021-09-16，娱乐独角兽采访、钛媒体授权刊发的[程璐、鸟鸟和张灏喆专访](https://www.tmtpost.com/5689428.html)。已读取采访正文；支持其关于内向表达、社恐题材、文本打磨和开放麦的自述，不代表现在只写这些题材。备用入口：2025-03-26 简单心理发布的[鸟鸟访谈（澎湃号）](https://www.thepaper.cn/newsDetail_forward_30490409)，已读取正文，可研究其情绪与创作的关系。
- **探索方向**：具体的内心活动、较低外放程度与文本结构；适合拿“表面顺从、内心反复演算”的作者样本做进一步比较。
- **观察任务**：选自己能合法观看的一段完整作品，记录一个担忧如何经过视角变化产生新解释，区分情绪认同和实际笑点。
- **原创练习**：写一次想拒绝却没拒绝的小事，分别写当场说出口的和脑内准备的，找二者冲突。
- **差异提醒**：作者不喜欢内心独白时，即使自称社恐也未必接近；不能根据这篇访谈确定某段的语速或停顿。

### 周奇墨

- **依据**：2021-10-16 环球人物网转载中国新闻周刊的[周奇墨自述](https://www.globalpeople.com.cn/channel/58/15667.html)。采访及报道支持日常观察、具体人物和模仿表演的学习方向；不是近期作品目录。
- **探索方向**：从普通人的语言和行为中找矛盾。与纯观点型稿比较时，关注“观点是否由人物自己演出来”。
- **观察任务**：同一角色靠哪些可见／可听的细节被辨认，删去模仿后还剩什么文本结构？需实际观看后作答。
- **原创练习**：观察自己生活中的一个人物，用两项非外貌的行为区分角色，再写其一次自相矛盾的动作。
- **差异提醒**：不擅长模仿的作者可以学观察，不必复制声线、口音或招牌人物。

### 呼兰

- **依据**：2025-05-10 极目新闻记者张聪的[《草台班子》专场采访](https://www.ctdsb.net/c1742_202505/2440908.html)。已读取原站正文，支持从自身工作环境和遭遇取材、关注观众体验的自述；不能当作完整专场逐字稿。2025-05-11 的荆楚网转载入口曾出现重定向问题，优先使用原站。
- **探索方向**：把大问题放回具体工作规则及自己遭遇的矛盾；暂作学习候选。
- **观察任务**：找一段可访问的正式作品，标出解释规则、展示例外、作者卷入三个位置；若不存在这些结构，就不要强行套用。
- **原创练习**：用自己的真实流程写“规则希望解决什么／执行后多出了什么事／我为了省事又做了什么”。
- **差异提醒**：职业相同不等于表达相近；仅凭采访不能判断其完整专场密度或用户与其强匹配。

### 徐志胜

- **依据**：2022-03-21 新民周刊[《专访徐志胜：喜剧的底色》](https://paper.xinmin.cn/html/xmzk/2022-03-21/18/27639.html)。可检索采访文字，直接访问曾超时，精确引用前复核。定位其日常观察、个人形象和创作讨论，不用于判断当前市场热度。
- **探索方向**：别人对“我”的预期与我自己的反应；需要进一步作品证据判断自我拆台与互动如何运作。
- **观察任务**：找出作品中观众已知信息与演员新提供信息的差别，判断笑点是否依赖名人身份。
- **原创练习**：用一个不涉及外貌的误认场景，写出自己顺势配合后出现的代价。
- **差异提醒**：作者未必有相同公众认知；不能复制自我外貌调侃、口音和固定搭档关系。

### 何广智

- **依据**：2025-09-22，[新华社采访入口（北京日报转载）](https://xinwen.bjd.com.cn/content/s68d1410be4b02424b0c08bac.html)。公开文字确认采访涉及从生活取材与未来计划；尚不足以支持对视频细节的分析。
- **探索方向**：普通生活中对资源、体面与关系的在意；这是待以具体作品复核的候选方向。
- **观察任务**：找一段完整正式作品，观察“想显得体面”是否通过行动暴露，还是只在台词里宣称。不要采用二手文章补写的“采访原话”。
- **原创练习**：从自己一次不愿承认的小算计写起，让算计产生新的具体后果。
- **差异提醒**：不要求作者扮穷；用户只讲职场时，也可能更适合其他机制不同的演员。

## 以官方作品目录为依据的探索入口

以下条目确认作品及题材；不把标题里的“炸场”“爆笑”等宣传词当评价。可通过官方入口自行观看，权益以平台为准。学习问题须由实际作品验证后，才升级为演员特征。

### 付航

- **作品**：《喜剧之王单口季》（2024）付航表演；[官方纯享目录](https://www.iqiyi.com/playlist6176376215239402.html)有英文表达与激情主题条目；[官方决赛个人片段](https://www.iqiyi.com/v_12iqgcr7i24.html)涉及表白经历。
- **观察任务**：动作、声音和叙述分别承担哪些信息？高能量的前后是否有反差，而非从头到尾只提高音量？
- **原创练习**：把自己的一个简单行动演成两个能量版本，台词保持相同，比较哪一处真正需要身体参与。
- **差异提醒**：作者不愿大动作表演时，先取动作与文本分工的方法，不把“更外放”当统一目标。

### 小鹿

- **作品**：《喜剧之王单口季》（2024）[官方节目页](https://www.iqiyi.com/a_26tz1mqh561.html)含婚礼与职场性别议题；[纯享目录](https://www.iqiyi.com/playlist6176376215239402.html)可定位生育期待主题。
- **观察任务**：观点如何从一件具体事进入？笑点改变的是角色地位、默认规则，还是听众对说话者的认识？
- **原创练习**：从作者亲历的一项不对等要求，写一次实际协商，保留自己的动机和小心思。
- **差异提醒**：议题认同与机制相似要分开；不把所有女性作者自动匹配到同一位演员。

### 刘旸（教主）

- **作品**：《喜剧之王单口季》（2024）[官方纯享目录](https://www.iqiyi.com/playlist6176376215239402.html)中的共享单车题材；2025 年[第二季第三期纯享入口](https://www.iq.com/play/the-king-of-stand-up-comedy-2-2025-7-26-wo5dmln2ag?lang=ja)。页面语言可切换，片段定位日期为 2025-07-26。
- **观察任务**：情绪变化怎样由具体行动推动？动作是在提供信息还是重复台词？
- **原创练习**：把自己一次急于证明能力的事分成三个动作阶段，只用一处强动作展示失控。
- **差异提醒**：不用先给作者贴“疯癫”标签；纯口播可以选择文本推进的练习。

### 唐香玉

- **作品**：《喜剧之王单口季》（2024）[官方纯享目录](https://www.iqiyi.com/playlist6176376215239402.html)含读书经历、被表白题材；可在目录内定位演员姓名。
- **观察任务**：具体生活关系如何交代？讲过去的自己时，现在的态度与当时的选择如何形成距离？
- **原创练习**：讲一次真实的人情往来，用当时原话和现在视角各写一句，再找到行动的反差。
- **差异提醒**：地域和亲密关系题材是入口，不能直接推断口音、性别或出身相似即风格相似。

### 于祥宇

- **作品**：《喜剧之王单口季》（2024）[第五期表演纯享目录](https://www.iqiyi.com/playlist8679133660065202.html)含哲学专业与就业题材；[总纯享目录](https://www.iqiyi.com/playlist6176376215239402.html)含租房、商场厕所题材。
- **观察任务**：日常经验与抽象观念在什么位置接上？推理有没有让问题具体化，而非增加听众的知识负担？
- **原创练习**：选自己一次小不便，用一个真实规则推到荒唐后果，再删掉不影响理解的术语。
- **差异提醒**：学历和知识储备不是推荐门槛，也不要求作者把简单事情讲复杂。

### 漆漆

- **作品**：《喜剧之王单口季第2季》（2025）[官方个人播单](https://www.iqiyi.com/playlist4848791737296302.html)，含西塘生活、朋友逛街、学生时代被配对等题材。
- **观察任务**：自我评价与外界评价如何冲突？从一个生活选择走到下一个后果时，是否更暴露说话者？
- **原创练习**：写自己一次“很有主见”却暴露犹豫的购物或社交决定，给出真实行动而非喊自信口号。
- **差异提醒**：不要复制身体叙事、固定自称或演员自己的生活经历；目录无法证明所有作品都用同一机制。

### 房主任

- **作品**：《喜剧之王单口季第2季》（2025）[官方节目目录](https://www.iqiyi.com/a_snmxdpmhdl.html)；[2025-07-11 官方短片入口](https://www.iq.com/short/15yrzo7e1fc?lang=zh_cn)可定位人生阶段变化题材；目录还列出客服工作内容。
- **观察任务**：叙述者的新选择如何改变旧关系？记下喜剧情境与情绪表达各自的功能，勿把感动当作笑声。
- **原创练习**：从自己已经发生的一个小变化写起，对照改变前后的一次日常对话，不制造创伤来提高戏剧性。
- **差异提醒**：年龄相似不够构成匹配；作者不愿公开家庭内容时，应换素材方向而非催促披露。
