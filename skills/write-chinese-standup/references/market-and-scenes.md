## 2. 先识别这次演出的共同背景

优先从用户信息中确认：观众为什么来、彼此是否熟悉、能否默认认识作者、是否共享行业知识、用哪种中文、时长和设备。只有缺项会实质影响写作时才提问；普通快速稿按合理默认继续。

不靠“某城市人爱这种笑话”“女观众只爱某议题”等刻板推断受众。城市、年龄和平台是需要验证的场景变量，不是性格结论。

## 3. 同一素材在不同场景怎么改

下表为创作与排练建议，不是行业统一标准或平台规则。

| 场景 | 优先交付 | 具体改法 | 观察什么 |
|---|---|---|---|
| 开放麦 | 一个能验证的短段 | 缩小实验范围，先建立关系与前提，保留试错空间 | 第一处听不懂在哪里；哪项变化影响反应 |
| 俱乐部拼盘 | 独立成立的短 set | 不依赖上一位演员铺垫；较早展示视角；准确控制时间 | 不熟悉作者的观众能否跟上，转场是否断气 |
| 售票专场／剧场 | 有人物与情绪发展的整体 | 强弱段搭配、回扣有新义、为叙事留呼吸 | 后半场是否只重复前半场观点，结尾是否有回报 |
| 综艺／比赛短 set | 在限定长度中迅速可理解的作品 | 保留独立故事单元；不用明星身份或掌声替文本补逻辑 | 不看字幕、没有熟人气氛时能否理解 |
| 商演／年会／校园 | 对共同经历的精准观察 | 把行业黑话变成情境，必要品牌信息融入动作；明确熟人梗可理解范围 | 圈外人能否理解；笑点是否只靠点名与配合鼓掌 |
| 短视频／口播 | 一个有完整前提与结尾的单元 | 首句建立问题；重写舞台上的长停顿；字幕不提前泄底；保留必要上下文 | 用户提供的完播、掉出位置、评论误读；不能单看播放量 |
| 粤语／方言／海外华语 | 对目标听众成立的版本 | 保留有用地域质地，解释必要关系；检查文字双关在声音中是否成立 | 非本地听者能否一次听懂；双语切换是否增加负担 |

泛称“商演”时先区分公开售票和品牌／企业活动，二者的共同背景与限制不同。已有活动要求直接遵循，不增加不必要的确认流程。

## 4. 适配动作

1. 锁住作者事实与核心矛盾，记录这次允许改变的部分。
2. 圈出只有原场观众知道的背景、名人关系和黑话，补最短必要解释。
3. 重新安排第一处有效信息、笑点揭示和结尾；压缩时删弱支线，不删除关键前提。
4. 舞台版给等笑与身体空间；口播版重新分句，不机械删除所有停顿。
5. 比较两版差异，明确一个验证变量。不因没有笑声就把整个人格换掉。

互动或 crowd work 只在用户需要时加入。设计“没有回应也能接回稿子”的退路，不把观众羞辱或虚构观众回答当成必需笑点。

## 5. 何时重新查市场

用户问“现在、今年、最新、哪个城市、买哪场、近期参考谁”时，当次检索。优先顺序：演员／俱乐部／主办方原始发布 → 正版平台完整作品 → 行业协会与一手采访；新闻稿的宣传判断要与事实分开。

搜索时分别覆盖目标城市或地区的线下项目、正式节目／作品、与作者相关的素材方向。判断趋势须比较时间和统计范围；找不到新证据就用较旧资料并明确日期，不把搜索抓取时间当出版时间，不补写未经核实的赛果或热度榜。

若只能看到搜索摘要，标“摘要线索”；链接为空壳、题文不符或来源互相抄录时换源。不为当前写稿任务收集无用的行业规模，也不让联网失败阻塞可完成的创作。
