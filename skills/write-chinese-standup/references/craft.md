# 中文脱口秀创作方法

## 1. 素材先于观点

优先追问可被看见的事实：

- 谁在场，地点有什么具体特征？
- 作者当时想得到什么，又害怕失去什么？
- 哪个动作、物件、数字或原话最反常？
- 作者嘴上怎么说，身体实际上怎么做？
- 如果删掉结论，只讲事情，听众还能感觉到作者的态度吗？

把“我发现现代人都很焦虑”改造成一个有时间、地点、行为和代价的事件。观点可以存在，但应由场景证明。

## 2. 选择喜剧引擎

每个段子先探索多个角度，再选最符合作者人格的一个。

- **反差**：身份与行为、期待与结果、口号与现实之间不一致。
- **误导**：让听众形成合理预期，在最后一个必要信息上改变解释。
- **升级**：同一逻辑连续变严重、变具体或变荒唐；每一级必须有新增信息。
- **类比**：用远距离但结构相似的事物照亮原场景。优先精确，避免“就像谈恋爱”式万能比喻。
- **三段式**：前两项建立规律，第三项破坏规律；第三项在句法上保持可比。
- **身份/地位翻转**：让看似强势的人暴露脆弱，让弱者短暂掌控规则。
- **Act-out**：用动作、声线、视线或角色对话展示冲突，不解释角色正在做什么。
- **具象化**：把抽象情绪变成可见行为、荒诞制度或具体物件。
- **回扣**：让早先出现的细节在新语境里获得第二层意思。
- **自我卷入**：作者不是站在外面评价世界，而是事件的参与者、受害者或共犯。

## 3. 搭建一个段落

使用下列功能，而不是机械套句式：

1. **定位**：最少信息交代人物、关系和地点。
2. **正常预期**：让听众知道一个正常人会怎样理解或行动。
3. **异常证据**：给出改变预期的具体事实。
4. **笑点**：在尽量靠后的词上完成反转、升级或形象化。
5. **Tag**：不重新解释前提，继续从同一发现挖一到三次。
6. **推进**：引入后果、新场景或新的情绪风险，避免原地换词。

如果 setup 比 punchline 长很多，先删除听众可以自行推断的信息。若 punchline 需要解释，则重新安排信息顺序。

## 4. 分开写手与主编

写手轮：

- 允许夸张、失败版本和不同角度。
- 一次生成多种机制，而不是同一句话的近义改写。
- 保留作者最真实、最有羞耻感或最具体的细节。

主编轮：

- 圈出每一句的功能：背景、人物、紧张、笑点、推进或回扣。
- 删除没有功能的句子和重复态度。
- 把笑点词尽量放到句尾。
- 检查每个 tag 是否比前一个新增画面或风险。
- 朗读；修改只能写出来、不能自然说出来的句子。

## 5. Punch-up 次序

按这个顺序修改，避免只堆更多比喻：

1. 修清楚：听众是否知道人、事、关系和时间顺序。
2. 修立场：作者到底惊讶、委屈、愤怒、尴尬、害怕还是暗自得意。
3. 修具体：加入真实原话、动作、物件、价格、地点或不整齐的小细节。
4. 修惊奇：隐藏哪条信息，或改变哪一个词，能让解释在最后翻转。
5. 修节奏：缩短 setup，前移必要事实，把笑点落在句尾。
6. 修表演：加入一个只有身体、声线或角色切换才能成立的瞬间。
7. 修连接：把孤立笑点转成后果、升级或后续场景。

## 6. 六维审稿表

每项 0–3 分；先修最低项。分数是诊断工具，不是假装客观的“搞笑指数”。

| 维度 | 0 分 | 1 分 | 2 分 | 3 分 |
|---|---|---|---|---|
| 真实 | 泛泛而谈 | 有事件无细节 | 细节可信 | 细节暴露人格与代价 |
| 清晰 | 听不懂关系 | 需要回读 | 一遍能懂 | 极少信息即建立预期 |
| 惊奇 | 可预测 | 只是夸张 | 有有效转向 | 转向意外且回看合理 |
| 声音 | 像通用文案 | 偶有作者口吻 | 基本能辨认作者 | 只能由这个人来说 |
| 可演 | 依赖文字解释 | 能读不能演 | 有节奏和角色 | 身体、停顿与文本互相增强 |
| 密度 | 长时间无回报 | 单一笑点 | 有 tag 或推进 | 笑点持续且不牺牲故事 |

## 7. 常见失败

- 用金句、升华或人生道理代替事件。
- 只给名词贴“离谱、绝了、破防”等标签，却没有证据。
- 每个笑点都使用“像谈恋爱、像上班、像前任”等通用类比。
- 为了“像脱口秀”而连续反问、喊口号或解释笑点。
- 模仿某位演员的标志性措辞、人生经历或独特节奏。
- 只有刻薄对象，没有作者自身的风险、欲望或共犯位置。
- 把模型生成的顺滑误认为现场可说；绕口和书面语必须朗读修正。

## 8. 观众反馈记忆

把反馈分成三层，避免 Agent 把一次偶然反应学成永久规则：

- **观察**：时间点、原台词、动作、反应开始与持续时间、下一句是否被盖住。
- **假设**：可能因为信息不清、预期不足、词序、表演、观众构成或敏感边界。
- **实验**：下一场只改变一个变量，并写明成功信号。

只有多次现场数据支持时，才把结论升级为长期风格规则。保留失败版本及场地信息，因为同一句话在不同观众面前可能表现不同。模拟观众只能用于暴露风险和歧义，不能替代真实笑声。

## 9. 中文表达的落地检查

这些是写作检查，不是所有中文观众都一样的断言。

- **关系要先听懂**：中文常省略主语，但两个人轮流说话时不能全是“他”。先交代谁能要求谁、谁不好意思拒绝，之后再省略。
- **潜台词变成动作**：把面子、人情、体面、客套等抽象词变成一次收礼、推辞、付款、点头或改口；让作者参与矛盾，不只站在外面点评。
- **落词不机械**：尽量延后改变理解的信息；如果硬挪词导致倒装和书面感，先保自然语序。笑点后的“你们懂吧／是不是特别离谱”通常削弱落点。
- **耳朵优先于字幕**：同音、断句、代词或字形梗要做无字幕朗读。只有看字才成立的梗，明确为视觉段子或改成听得懂的版本。
- **真实口语不是热词堆积**：保留作者自然使用的词，不额外铺满“家人们、我真的会谢、谁懂啊”。热词如果承担不了新信息就删。
- **吐槽里有自我位置**：指出流程荒唐后，再追一层自己为何服从、钻空子或想占便宜。不能把所有人写成对世界全知全能的裁判。
- **情绪可以不同**：犀利不等于大声；温和不等于没有态度；自嘲不必贬低尊严；严肃题材也不要求鸡汤式升华。

### 原创微型示例：从观点到动作

以下完全虚构，仅示范结构，不是任何演员台词或用户真实经历。

原稿：“现在会员套路很多，总让我觉得被资本拿捏。”

改写：“我买了健身房年卡。前台问我：主要练哪块？我说，主要练每次路过这儿，都能假装没看见。”

变化：用办卡与回避的行动交代自我矛盾；前台的问题建立正常预期，回答改变“训练目标”。这里“年卡、前台对话”属于创作设定，套用到真实作者前须确认或替换。该示例只是候选笑点，未经现场验证。

## 10. 用观察定位问题

| 观察 | 可能原因（不能直接定论） | 优先做的一次实验 |
|---|---|---|
| 到包袱才听不懂人物是谁 | 关系铺垫不足、代词混乱 | 提前一个称谓，其他不变 |
| 观众点头但没有笑声 | 只有共鸣、结论可预测，也可能声音没传到 | 加一个改变解释的事实，保留原立场 |
| 观众提前笑，最后一句没反应 | 信息过早泄露，或前面已是有效笑点 | 把前面当落点，试删尾部解释 |
| 现场有人喊“然后呢” | 只有态度重复，没有后果 | 续写一个实际行动及代价 |
| 录音里笑声盖住下一句 | 抢 tag、没给动作和反应时间 | 只调整等笑，不同时换文本 |
| 同稿在另一场变冷 | 共同背景、位置、设备、观众构成或发挥变化 | 先记录场景差异，别马上重写所有包袱 |

复盘允许“暂时无法判断”。缺原稿和反应记录时，先保存作者能回忆的原版，拿不准处留空；下一场可以只采集基线，之后再做单变量实验。不要为填满诊断表虚构原因；用真实版本对照来减少猜测。
