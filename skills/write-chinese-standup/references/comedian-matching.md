# 相似演员推荐与作品学习

目标：让作者找到可借鉴的方法，并知道自己与参考演员的差别。种子库只是检索起点，不是热度榜、能力排行榜或穷尽的演员名单。

## 1. 识别推荐依据

- **“我的稿像谁”**：先摘出稿中支持判断的短句或叙事特征，只对当前样本下结论。
- **“我喜欢某演员，推荐类似的”**：依据用户喜欢的作品或特征推荐观看对象，不自动建立用户本人风格档案。
- **“我是新人，想学谁”**：结合希望学习的能力和现有样本，给低门槛练习；若没样本，给探索路线而非“你就是某某型”。
- **“这个演员还有谁比较像”**：比较具体作品的机制、语感或表演，不把双方终身归为一个标签。
- **“最新／当前人气演员”**：独立核查新作品和公开数据；不能拿库中的旧作品推断当前热度。

如缺信息，最多先问一个会改变匹配的问题；也可以给明确标注“探索性”的 2–3 条路线，让用户有东西可选。推荐无需用户先填长问卷。

## 2. 沿六个维度比较

| 维度 | 判断问题 |
|---|---|
| 观察对象 | 具体在讲哪类关系和生活场景？ |
| 作者位置 | 受困、自我拆台、较真旁观、挑战规则，还是参与制造问题？ |
| 喜剧机制 | 反转、类比、推演、升级、人物表演、荒诞具体化如何工作？ |
| 叙事结构 | 短句密集、完整故事、连续论证还是松散观察？ |
| 语言质地 | 克制、口语、细密、方言、直给等是否有样本依据？ |
| 表演依赖 | 笑点依赖声音、身体、节奏、互动到什么程度？ |

优先让**作者位置和喜剧机制**相近，再看叙事、语言和表演条件。题材只是入口。同为女性、山东人、程序员、低收入者或内向者不构成匹配证据。只有文字样本时，表演维度保留未知；不要给“相似度 92%”等无测量依据的数字。

每个“相似参考”至少说明两项有证据的共同点，其中一项应是作者位置或机制，并指出一个实际差异。证据不足则叫“可探索的学习对象”，不要凑出强匹配。

## 3. 输出能执行的推荐

通常推荐 2 位相似参考和 1 位互补参考；不强求数量，也不自动列十几个名人。每项包含：

1. **为什么匹配**：对应用户哪一句或哪种具体表达。
2. **哪里不同**：如对方依赖高能量动作，而用户希望坐着录口播。
3. **从哪里看／读**：作品或访谈名称、年份、发布方、可核验链接；付费／会员或只有介绍页时如实说明。
4. **学什么**：一个可迁移的方法和一个具体观察问题。
5. **怎么练**：把方法换到用户自己的另一件事里，交付一个原创练习。
6. **判断限度**：已观察作品／有一手采访／仅有官方目录等，选择恰当的置信表述。

可用短表“演员与入口｜相似点／差异｜学习任务”，不用强制输出六个小标题。综合匹配可信度不能高于用户样本和演员证据中较弱的一方。

## 4. 检索与证据等级

查[演员种子库](comedian-library.md)相关条目即可，不要把全库载入每次写稿。用户指定库外演员、地区或近期作品时扩展检索。

- **直接作品证据**：用户提供的片段、可访问的完整表演或可靠转写。只对实际读到／听到／看到的范围做机制判断；分析节奏和动作需要相应视听证据。
- **一手访谈证据**：演员自述或采访，可支持创作方法与公开经历；不能替代对具体段子停顿的观察。
- **官方目录证据**：平台、演员、主办方的标题和简介，可确认作品入口与题材。机制、能量、动作和节奏只列为待观察问题。
- **线索**：搜索摘要、评论或二次剪辑，只用于找到原始来源。摘要与正文有冲突、演员同名、平台占位页等情况须降级或换源。

没有看过视频就不要说“看完后发现”；页面能打开也不等于完整内容免费可看。找不到精确时间点就给作品定位信息，不编造分钟数、期数、专场名或链接。找不到可靠入口时换一个证据更好的候选，或保留待核查状态。

## 5. 学习到原创的隔离步骤

先把参考拆成不含台词的结构，例如“立规则 → 自己获益 → 规则反过来约束自己”。再关闭参考，从作者另一段真实经历重建人物、行动、逻辑和结尾。检查是否沿用了对方独有的场景组合、反转路径或连续措辞；仅替换名词不算原创。

不要借用参考演员的创伤、残障、阶层经历或口音给作者造人设。不要为了与推荐演员相似而删掉作者作品里的有效差异。若用户要模仿，简短转为“克制表达、具体观察、低声量”等一般技巧，随后完成原创任务。

## 6. 更新方式

演员卡记录“作品年份、核查日期、入口、证据层级、可支持的事实、学习假设”；优先补充作者目标场景需要的样本。基础作品可以长期保留，旧作品不伪装成近期动态。一次推荐后，只有作者确认有帮助才写入长期档案；不把系统的推荐自动变成作者喜好。
