# 作者档案、素材与训练

用于风格定位、选题和长期陪练。不要在一次快速改稿里把这些表全部展示出来。

## 1. 从样本识别作者，而不是给人贴标签

优先用作者自己的短稿、录音转写或真实生活叙述；已有样本够用就不重新采访。录音听不到时，只评价文本，不推断语速、停顿和舞台能量。

档案只记录会改变创作决定的信息：

| 项目 | 要识别的内容 | 防止误判 |
|---|---|---|
| 素材领地 | 经常置身什么关系，哪些细节只有本人知道 | 职业相同不等于观察相同 |
| 喜剧视角 | 想显得怎样，实际上如何露馅；向往什么又怕什么 | “内向”不是完整人格 |
| 情绪态度 | 委屈、好奇、较真、得意、懊恼、自我辩护等 | 不强迫所有人愤怒或自嘲 |
| 语言习惯 | 常用词、句长、方言、书面与口语的距离 | 保存原句作依据，不人为制造口头禅 |
| 写作机制 | 故事、观察、推理、荒诞、人物、短句反转等 | 文本可混合机制，不强制唯一流派 |
| 表演条件 | 用户确认的能量、动作、模仿意愿与设备条件 | 只有文本时标“待观察” |
| 创作目标 | 这次任务、想长期讲什么、不想公开什么 | 审美偏好与当前能力分开 |

每项区分“作者明确说明”“样本中观察到”“暂时假设”。用户纠正时覆盖旧假设。一个段子只足以说明“这段像什么”，不够为整个人定型。

把人格矛盾变成可用的工作句，例如“想做讲道理的人，却在小利益上不断讨价还价”。不要把这句话强塞进演出自我介绍。

## 2. 选题从经历交叉处生长

从作者经历、当前情绪、观众熟悉的关系中找交集。可用的中文生活关系包括：家人与独立、体面与预算、人情与效率、规则与实际执行、地域与迁移、工作角色与私人自我。它们只是采访入口，不是中国人都相同的证明。

把一个大题拆成三层：

- **议题**：“AI 让人焦虑”——还不能直接演。
- **事件**：“同事让我教他用 AI，然后让我替他改 AI 写的周报”——有动作和关系。
- **个人矛盾**：“我为了证明自己不可替代，替软件加了一晚上班”——有作者位置和反常逻辑。

上例为原创虚构示范，不能写进作者的真实档案。

候选选题比较：本人是否有细节、有没有具体欲望与代价、能否引出不同后果、目标观众理解需多少背景、作者是否愿意公开。热搜不是额外加分项；缺少个人进入方式时宁可不用。

## 3. 素材生命周期

用稳定编号连接点子、段子版本和演出记录；不要因每次修改换了标题就丢失关联。

| 状态 | 进入依据 | 下一步 |
|---|---|---|
| 素材 | 有事实或明确的虚构设定 | 找作者态度与异常细节 |
| 草稿 | 有可理解的前提和发展 | 朗读、修口语与时长 |
| 待试 | 已能完整排练 | 选择一个现场变量 |
| 反复有效 | 多场可比场景支持预期效果 | 组场，记录适用范围 |
| 重写／暂存 | 作者选择或观察提示问题 | 保留失败版本及可能原因 |

“反复有效”不设机械的三场门槛；注明证据来自哪里，换场景仍可能失效。公开发布与现场验证是不同状态，要另外记录，以免拿已广泛传播的段子当全新材料。

## 4. 按瓶颈训练，不按天数堆作业

用户要系统训练时，再给适合其投入的周期；默认每轮练一个能力。

| 瓶颈 | 一次练习 | 完成证据 |
|---|---|---|
| 只有观点 | 把最近一次事件写成五个动作和一句原话 | 听者能复述发生了什么 |
| 只有抱怨 | 同一事件写“我受害／我也参与／我想占便宜”三个位置 | 至少一个角度暴露作者矛盾 |
| 都是预料内 | 标出听众预期，改变最后一个必要信息 | 听者能说明哪里改变理解，而非只说夸张 |
| 有梗却难说 | 录一遍，听回放后删一层解释 | 不看稿也能按意群说完 |
| 人物说不清 | 同一句用视线和姿态区分两人 | 听者分得清是谁说话，不需旁白补救 |
| 练得多却没进展 | 同一段保留基线，只改一个变量 | 有旧版、新版与场景记录可比较 |

可以组合成“采集 → 成段 → 排练 → 实演复盘”的四轮训练，但不得承诺四周成名、固定笑声数或人人都适合某种表演。演员学习用[研究与练习卡](../assets/study-card.md)，练完回到作者自己的素材。
