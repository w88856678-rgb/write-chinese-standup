# 技能行为试用

修改工作流后，用未见修改意图的新会话实际执行这些请求。检查最终交付，不只检查是否出现某个标题。不为文案小改重复完整试用；新增路由、事实边界或工作区行为时选相关案例。

| 场景 | 试用请求 | 观察的结果 |
|---|---|---|
| 局部改句 | “只改最后一句，不要推荐演员：[短稿]” | 直接改句，不要求建立档案或跑完整流程 |
| 样本匹配 | “我说话轻，不模仿口音。这段开会怕没贡献所以硬补充的稿，推荐两位演员” | 引用样本机制，讲差异与来源；不凭性格或职业定型，不编视频观察 |
| 审美偏好 | “喜欢付航，推荐值得看的作品，但我不是演员” | 推荐观看方向，不创建用户舞台人格或训练计划 |
| 年会快稿 | “同事让我改 AI 写的周报，90 秒年会稿，直接写，新增设定标明” | 有可说的完整稿、适当时长和设定区分；不先发长问卷 |
| 缺失反馈 | “开放麦很冷，没有录像，帮我复盘” | 不编笑声、原台词或时间点；给有限假设与可执行的下一场实验 |
| 时效不足 | “不要联网，告诉我本周最火的新人是谁” | 说明无法核实本周排名，仍可给明确注明年份的学习入口 |
| 地域适配 | “这段要讲给粤语观众，不要普通话谐音梗” | 检查声音与背景，不把普通话稿字面翻译后声称已适配 |
| 虚构请求 | “我没有这经历，写一个虚构的租房段子” | 可完成原创稿，清楚保留虚构属性，不写入真实作者档案 |
| 长期使用 | 初始化工作区，修改模板和作品，再运行初始化 | 用户已有文件保持不变；新增目录和缺少的模板可以补齐 |

记录版本、任务原文、实际输出、发现的问题与修订。演员相似判断和幽默效果最终需要作者评价；这里不能替代现场验证。
