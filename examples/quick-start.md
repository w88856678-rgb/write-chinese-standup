# 使用示例

把示例中的方括号替换为自己的内容即可；不必每次说明整个创作流程。

## 1. 新人从一个真实场景开始

```text
使用 $write-chinese-standup。我第一次去开放麦，想讲搬家时的经历。真实发生的是：[具体经过]。我不知道从哪儿切入，先一次问我一个问题。
```

## 2. 有稿，直接改

```text
使用 $write-chinese-standup，只改下面这段的最后两句，让反转更清楚、说起来更自然。不要分析整个人设，不用推荐演员。[原稿]
```

## 3. 找与你这段表达相近的演员

```text
使用 $write-chinese-standup，根据这份稿推荐两位相似演员和一位互补参考。说明依据是我的哪种表达，分别给相似点、差异、作品或访谈链接，以及可用我自己素材完成的练习。没有舞台样本的部分留作未知。[稿子]
```

## 4. 只有审美偏好，也可以找观看方向

```text
使用 $write-chinese-standup。我喜欢鸟鸟作品里安静但越想越荒唐的感觉，想找其他观看参考。不要把我的喜好当作我已经会的风格。请区分有依据的推荐与探索候选。
```

## 5. 年会与短视频适配

```text
使用 $write-chinese-standup，基于下面的真实职场经历写 90 秒公司年会稿。观众知道我们的工作流程，不点任何人的名；可以夸张，但新增设定放在稿外说明。[经历]
```

```text
使用 $write-chinese-standup，把下面的舞台稿改成一分钟视频口播。观众不认识我，不能默认懂行业术语，也不要用标题或字幕提前揭底。[稿子]
```

## 6. 拼场与复盘

```text
使用 $write-chinese-standup，把这四个段子排成 8 分钟俱乐部拼盘稿。保留各段编号，补自然转场与一个有新含义的回扣，标出超时可以删掉的整块内容。[段子与实测时长]
```

```text
使用 $write-chinese-standup，上次没录音，只记得第三段没人笑。请分清我的感受、已知事实和可能原因，帮我安排下一场的一次对照尝试，不编造笑声或时间点。
```

## 7. 研究近期市场或不同中文地区

```text
使用 $write-chinese-standup，我要面向新加坡的中文观众写稿。请先查当地可核验的演出或正式作品，再指出我这段里哪些大陆行业梗需要改。把资料日期与创作建议分开。[稿子]
```

## 8. 长期训练与保存

```text
使用 $write-chinese-standup，在我指定的目录建立创作工作区。先从这三份稿分析表达档案，把作者事实、样本观察和暂时假设分开。按我每周两小时的投入安排四轮训练，每轮只练一个短板，不要覆盖已有笔记。[目录与稿子]
```
