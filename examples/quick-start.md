# 五分钟上手

下面的素材均为虚构示范，不代表真实人物经历。

## 1. 先记点子

```text
使用 $write-chinese-standup，先帮我记一个点子，不要急着写笑话：
公司说这次活动要“自由发挥”，但同时发了一个 27 页的统一模板。
```

适合你只有一个观察、还不确定哪里好笑的时候。

## 2. 展开成段子

```text
使用 $write-chinese-standup，把这个真实经历发展成约 3 分钟的段子。
一次只问我一个最重要的问题，不要替我编造经历。
```

Skill 会优先追问人物、地点、原话、动作、欲望、阻碍和最尴尬的具体细节。

## 3. 快速成稿

```text
使用 $write-chinese-standup，根据我现有的信息先快速写一版。
缺少的事实请明确标成假设，不要把假设说成我的真实经历。
```

适合临时排练；之后仍建议补充真实细节。

## 4. 加强已有稿件

```text
使用 $write-chinese-standup 审这份稿。
先指出最影响现场效果的一个瓶颈，再给出完整修改版；保留我原来有辨识度的句子。
```

## 5. 添加表演标记

```text
使用 $write-chinese-standup 给稿子添加稀疏的人类可读表演标记。
只标真正影响意思和笑点的位置，不要把每句话都标满。
```

主要标记包括 `/` 短停、`//` 节拍停顿、`///` 等笑，以及重读、动作、状态和角色切换。

## 6. 演完以后怎么改

```text
使用 $write-chinese-standup 帮我看看这次开放麦记录。
告诉我哪些地方有效、哪些地方没讲清楚，以及下次最应该先改哪一处。
```

电脑的判断只能提醒你哪里可能听不懂。真正的改稿依据，仍然是你的朗读、录像和现场反应。
